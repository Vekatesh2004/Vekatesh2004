## Featured Projects

### 1. Antimicrobial Resistance Analysis in *Acinetobacter baumannii*
**Domain:** Microbial Genomics · AMR · Whole-Genome Sequencing

A research workflow focused on identifying and analysing antimicrobial-resistance genes from bacterial sequencing data.

- Process paired-end WGS reads and assess read quality.
- Explore genome assembly, assembly quality assessment, and annotation.
- Analyse resistance-associated genes using CARD/RGI and related AMR resources.
- Combine results into tables and visual summaries for comparative interpretation.
- Explore comparative-genomics and phylogenetic analyses.

**Tools explored:** fastp, FastQC, MultiQC, SPAdes, QUAST, BUSCO, Prokka, RGI/CARD, MAFFT, IQ-TREE, Python, R, Linux.

### 2. RNA-seq Differential Expression and Functional Analysis
**Domain:** Transcriptomics · Statistical Analysis · Functional Enrichment

An analysis workflow using gene-count data to explore differential expression and downstream biological interpretation.

- Prepare and validate gene-count matrices and sample metadata.
- Run differential-expression analysis with DESeq2.
- Visualise expression patterns with heatmaps and principal-component analysis.
- Explore Gene Ontology (GO) and KEGG pathway enrichment for *Oryza sativa*.

**Tools:** R, DESeq2, ggplot2, pheatmap, Bioconductor enrichment tools.
